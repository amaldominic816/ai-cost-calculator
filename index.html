How LLM API Pricing Formulas Work

Language model APIs charge per one million tokens (1M tokens is roughly 750,000 English words). Total billing involves three critical components: input tokens, output tokens (which cost 3x to 5x more due to sequential generation overhead), and context cache hits.

What is prompt caching?

Prompt caching allows APIs like Anthropic, OpenAI, and DeepSeek to index large repetitive prompts. When the input matches, you get discounted reads that cost up to 90% less.

Why use the Batch API?

If your workload does not require instant millisecond responses, Batch endpoints queue jobs within a 24-hour SLA window in exchange for a flat 50% pricing cut across all tokens.
